Cómo funciona esta demo

1. Introduce una pregunta.
2. Se buscan coincidencias en fichas documentales.
3. Se presenta una respuesta y su fuente.
4. Puedes abrir una plantilla o crear una tarea.

Limitación: no hay un modelo de IA conectado. No se deben introducir datos personales reales ni confiar en este prototipo para calcular plazos legales.
